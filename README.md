# It-s-Football-not-Soccer

### The Question that I hope to answer through this project
How much the current state of Football play can tell about it's future ?

### Initial Direction
The project will begin by investigating:

- How goals are distributed in football matches
- Whether standard probability distributions can adequately model goal scoring
- How scoreline and match time affect the probability of different outcomes
- Whether a football match can be represented as a sequence of probabilistic states
- Whether stochastic processes such as Markov Chains can provide a useful representation of match dynamics

These are just initial ideas, not fixed ones. These could evolve as the project moves forward. 

Starting with one of the recent papers that goes into a similar track titled 'A Bayesian bivariate conditional Poisson regression for goal dependence in the English Premier League' by Nolan et.al. 

Researched further about what all kind of models have been used/ previous works on the related field

After researching about analyzing football, I learnt that multiple models do that.
